# Notation downloads

Notation is Greg Spero's keyboard-first music notation editor for macOS. You type notes from the keyboard, the score renders as you go, and the file is plain MEI.

Site: https://notation.gregspero.com

## Download

Latest: [Notation 0.1.0 (Phase 0)](https://github.com/therecordingclub/trc-notation-releases/releases/tag/v0.1.0-phase0)

Requires an Apple silicon Mac on macOS 13 or later.

## First open

Notation.app is unsigned by Apple: the first open is blocked; System Settings > Privacy & Security > Open Anyway, once.

1. Unzip the download and move Notation.app to Applications.
2. Double-click it. macOS says it cannot verify the developer. Click Done.
3. Open System Settings > Privacy & Security, scroll to Security, click Open Anyway next to "Notation.app was blocked", and confirm.

Later launches open normally.

This repository holds release files only. The source is private.
